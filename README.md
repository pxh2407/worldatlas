# 🌍 World Atlas Explorer

Atlante interattivo del mondo: esplora i Paesi su una mappa e scopri le loro informazioni
(capitale, popolazione, valuta, superficie, lingue, confini…). Interfaccia in **italiano e inglese**.

**➡️ Sito online:** https://pxh2407.github.io/worldatlas/

## Caratteristiche

- Mappa politica interattiva (trascina per spostarti, pulsanti +/− per lo zoom)
- Scheda dettagliata per ogni Paese, con numero di abitanti
- Filtro per continente e elenco completo dei Paesi
- Interruttore lingua **IT / EN** (in alto a destra)

I dati provengono dai dataset pubblici [`mledoze/countries`](https://github.com/mledoze/countries)
e [`datasets/geo-countries`](https://github.com/datasets/geo-countries); la popolazione è da World Bank.
